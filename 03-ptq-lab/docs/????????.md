## 如果机器没关机

说明有步骤失败。查日志里的 `✗`：

```bash
grep -n "✗\|⏭\|失败" "D:/WorkBuddy/ShowBro/lab/03-ptq-lab/docs/_夜间运行日志.txt"
```

常见原因：
- 显存不足（OOM）—— 两个任务抢 GPU
- 训练脚本参数问题

**没关机是故意的**：宁可让你明早看到"失败了"，也不要"没跑完还关机了"。

## 关于自动关机的实现

```bash
/mnt/c/Windows/System32/shutdown.exe /s /t 60 /f
```

60 秒延迟，足够写完日志。已验证 `shutdown.exe` 在 WSL 里可用。
