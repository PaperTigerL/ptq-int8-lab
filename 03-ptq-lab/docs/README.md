## ⚠️ 关于「留档」文件的说明

**这些带 `_` 前缀的文件是历史快照，不是当前结论。**

特别是 `_核心发现_v1.md` —— 它写着「回收率稳定在 0.85」，
**这个说法已被第四个数据点推翻**（实际是 0.77–0.86，且按数据集聚类）。
**当前结论请看 `核心发现-收益上界由量化友好度决定.md`。**

保留它的理由：**记录一个错误判断是怎么形成的** ——
两个 CIFAR-10 组合的回收率极其接近（0.86 / 0.85），
很容易让人以为找到了常量。这个陷阱值得留档。
